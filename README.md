# 2026 Sikand Symposium CNN Workshop
This repository contains the code presented during the AI/ML Club's workshop at the symposium.

## Getting Started
To run the scripts, `keras`, PyTorch (`torch` and `torchvision`), and PIL (`pillow`) are needed.

Then, play around with it!
- Note that you'll need to adjust the location in which `gui.py` expects the model to be at.

## Training
Find the Kaggle dataset here: https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia/data

Note that you can download a trained model here: https://drive.google.com/drive/folders/1QckplakmvWyHaowVqy6MH4mf7fNojSPk
